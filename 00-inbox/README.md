# 00-inbox

Unsortierter Eingang. Alles, was noch keinem Lebensbereich zugeordnet ist, landet hier zuerst: schnelle Notizen, hochgeladene Dateien, offene Gedanken.

Keine feste Unterstruktur. Wird regelmäßig durchgegangen und in den passenden `0X-bereich/` (`data/`, `briefings/` oder `decisions/`) einsortiert, danach hier gelöscht.

Boundary: P1, Standard. Enthält aber potenziell noch unsortierte P0-Inhalte, im Zweifel wie P0 behandeln bis einsortiert.
