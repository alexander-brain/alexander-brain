# 90-archive

Abgeschlossene oder veraltete Inhalte aus allen Lebensbereichen. Nichts wird gelöscht, was einmal Wahrheit war, es wandert stattdessen hierher.

Struktur beim Verschieben beibehalten, zum Beispiel `90-archive/04-finanzen/2024-altes-depot.md`, damit die Herkunft nachvollziehbar bleibt.
