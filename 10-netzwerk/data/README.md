# data/

Wahrheitsdaten des Netzwerk-Bereichs.

- `kontakte.csv` vollständiger Kontaktbestand, ein Kontakt pro Zeile.
- `gruppen-business-kontext.md` dieselben Daten geclustert nach Firmenfeld, für die schnelle Suche nach passenden Kontakten.

Beide Dateien werden gemeinsam aus einem Kontaktexport erzeugt. Bei neuem Export beide Dateien ersetzen, nicht von Hand einzeln nachpflegen, sonst laufen sie auseinander.
